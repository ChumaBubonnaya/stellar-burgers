Тесты Jest вызывают редьюсеры напрямую с конкретными состояниями и действиями.
Дополнительно проверяются уникальные идентификаторы повторных добавлений,
перестановка в обе стороны, неправильные индексы, неизменность входных объектов,
стоимость двух половинок булки, пустой ответ API и запрет параллельной загрузки
каталога. Отдельные проверки выполняют настоящий thunk загрузки с подменённой
функцией API и реальным Redux store.

Playwright запускает приложение в браузере и проверяет результат действий
пользователя. HAR содержит только вымышленные данные. Подстановка ответов
настроена для всех запросов учебного API; запрос без подходящей HAR-записи
прерывается и считается ошибкой теста. Изображения в ответах встроены как data URL.

При успешном заказе проверяется тело POST-запроса: булка в начале и конце,
между ними начинка и соус, а также заголовок авторизации. После ответа сверяются
номер `73142`, пустой конструктор и закрытие квитанции. При ответе 503 проверяются
сообщение ошибки и сохранение всего бургера.

В рабочий интерфейс добавлен только `data-testid="modal-overlay"` для надёжного
выбора затемнённого фона в тесте. Поведение приложения сохранено.

## Запуск

Нужны Node.js 22.12+ или 24 и npm. Команды выполняются в корне проекта:

```bash
npm ci
npx playwright install chromium
npm test
npm run test:coverage
npm run e2e
npm run typecheck
npm run check
npm run build
```

Для тестов отдельно запускать приложение и создавать аккаунт не требуется.
Playwright сам поднимает Vite на `http://127.0.0.1:4000`, задаёт адрес тестового API
и использует HAR. Перед запуском освободите порт 4000, если приложение уже
запущено в другом терминале. Локальные файлы `.env` для тестов не нужны.

`npm run e2e:ui` открывает интерфейс Playwright.
`npx playwright show-report` открывает HTML-отчёт браузерного запуска.
`coverage/index.html` содержит отчёт о покрытии Jest.

Для обычного запуска приложения используйте `npm start`. При необходимости
скопируйте `.env.example` в `.env` и укажите свой адрес учебного API.

## Результат проверки

Проверено 21 ноября 2026 года:

- Jest: 3 набора, 40 тестов — успешно.
- `catalog.ts` и `builder.ts`: 100% строк, операторов, ветвей и функций.
- Playwright: 10 сценариев — успешно в Chromium Headless 143.
- TypeScript: приложение, Jest, Playwright и конфигурация сборки — успешно.
- ESLint и Stylelint: успешно.
- Production-сборка: успешно.

Показатель 100% относится к двум указанным слайсам, а не ко всему приложению.

В среде подготовки недоступна загрузка стандартного браузера Playwright, а
запуск системного Chromium ограничен. Поэтому браузерные сценарии выполнены
с отдельной локальной конфигурацией и доступным Chromium Headless. Этот
временный запускатель в архив не включён. Пользовательская конфигурация
рассчитана на браузер из `npx playwright install chromium`. При необходимости
можно задать путь к установленному браузеру переменной
`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

Новые тесты и фиктивные ответы написаны для интерфейсов этого репозитория.
Готовые тесты из другого проекта не переносились. Общий учебный стартер и код
предыдущего принятого этапа сохранены; результат закрытой системы проверки
заимствований гарантировать невозможно.
